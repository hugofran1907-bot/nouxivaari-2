## Cómo Usar

1. **Descargar la carpeta** `xivarri-web/`
2. **Abrir** cualquier archivo `.html` en el navegador
3. **Listo** - No requiere instalación ni servidor

## Para Publicar Online

- **Vercel**: Arrastra la carpeta a vercel.com
- **Netlify**: Sube los archivos a netlify.com
- **Tu hosting**: Sube los `.html` por FTP/SFTP
